# DSH Images 社区玩法

[English](README.md) | 简体中文

大家分享给 [DSH Images](https://github.com/kadaliao/dsh-images)（DeepSeek Harness 的生图插件）的玩法。
插件每周读取一次 [`index.json`](index.json)：合并进来的每个玩法，都会出现在所有订阅了这个源（默认就订阅）的人的
**图片 → 玩法 → 社区** 里。

一个玩法（配方）就是一段试过效果的提示词模板：带几个空（`{{名字}}`，每个都有默认值），定好尺寸或动图参数，注明作者。
在插件里填好空、点「用它开始创作」，模型就会用 `generate_image` 按它画图。

## 分享一个玩法

1. 在图片面板里打开你自己的一个玩法（**玩法 → 我的**；任何一张图都可以用 **⋯ → 存为玩法** 变成玩法），点
   **分享到社区**。面板会先完整展示将要公开的内容（标题、简介、提示词、参数；你的照片和对话一律不会上传），
   然后在这里新开一个 issue，配方已经填好。
2. 把一张用这个玩法画的图拖进 issue 的 **封面** 栏，勾选确认项后提交。
   （手边没有插件：[打开投稿表单](../../issues/new?template=recipe.yml)，粘贴配方串或配方 JSON。）
3. `intake` 工作流会检查配方，然后开一个包含配方和封面的 PR。有问题时它会在评论里说明；改好 issue 会自动重新检查。
4. PR 合并后，`index` 工作流重建 `index.json`，issue 会被打上 `published` 标签。

issue 会一直开着，作为这个玩法的主页：**给它点 👍 就是投票**，用它画的作品贴在评论里。插件里的
**晒到作品墙** 会复制你的图并打开这个页面。投票数和作品数每天统计进索引一次，插件按投票数给社区玩法排序。

## 规则

- 自己写的，或者注明出处、且原作许可允许这样分享的。
- 不涉及真实公众人物；不点名受版权保护的角色、作品系列、品牌、工作室或在世艺术家，改为直接描述风格；
  没有色情、血腥或仇恨内容。
- 提示词里不能有链接。玩法合并前会经过人工审核；插件也会告诉对话模型：社区玩法是别人写的文字，只能当作
  生图提示词使用，不能当成对它的指令。

## 自己办一个源

任何能通过 HTTPS 访问、格式如下的索引都可以作为订阅源，在 **图片 → 玩法 → 订阅源** 里添加即可。团队可以
fork 这个仓库，也可以只放一个文件（格式见[英文说明](README.md#run-your-own-source)）。格式由
[`scripts/recipe-format.mjs`](scripts/recipe-format.mjs) 校验，它是插件 `lib/recipes.mjs` 的副本。

## 部署一份副本

建好仓库后：创建 `recipe`、`needs-fix`、`published` 三个标签；在 **Settings → Actions → General** 里给工作流
读写权限，并允许 GitHub Actions 创建 PR。
